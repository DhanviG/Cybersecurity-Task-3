# Task 3 – Wireshark Packet Analysis

## Objective
The objective of this task was to capture and analyze network traffic in a safe, controlled, and authorized testing environment.

## Overview
This task involved capturing network traffic generated while interacting with a web application and analyzing the packets to understand network communication and different protocols.

## Activities Performed
* Selected the appropriate network interface for packet capture.
* Captured network traffic.
* Filtered and analyzed **HTTP traffic**.
* Filtered and analyzed **DNS traffic**.
* Examined packet details and protocol information.
* Analyzed network communication for security-related observations.

## Learning Outcome
This task provided practical experience in network packet capture and analysis and helped in understanding how packet analysis can be used for network monitoring and security analysis.
